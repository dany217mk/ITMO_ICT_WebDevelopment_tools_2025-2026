    Предметная область

    Создать программную систему, предназначенную для работы маркетплейса охранных услуг. Система должна обеспечивать хранение сведений об охранных компаниях, об услугах, которые они предоставляют, о пользователях, формирующих заявки на услуги, а также о владельцах компаний, управляющих своей организацией на платформе. В системе могут регистрироваться пользователи, которые получают возможность либо использовать платформу для поиска охранных услуг, либо создать собственную охранную компанию. Пользователь, создавший компанию, становится её администратором. Охранная компания характеризуется названием, описанием и перечнем оказываемых услуг. Каждая услуга имеет название, описание и стоимость. У разных компаний стоимость одинаковых по содержанию услуг может различаться. Также система позволяет компаниям создавать скидки и акции на свои услуги, которые могут действовать в определённые даты и применяться к конкретным услугам. Обычный пользователь имеет возможность просматривать каталог компаний, фильтровать их по оказываемым услугам, знакомиться с информацией о компании и её стоимости услуг. Пользователь может отправить запрос на оказание услуги выбранной компании. Такая заявка фиксируется в системе и поступает администратору компании. Администратор может просматривать поступившие заявки и изменять их состояние (новая, принята, отклонена). Также пользователи могут оставлять отзывы об охранных компаниях, включающие числовую оценку и текстовый комментарий. На основании отзывов можно определить средний рейтинг компании. Кроме того, пользователи имеют возможность добавлять услуги в избранное.

    Работа с системой предполагает получение следующей информации: - список компаний, оказывающих заданный вид услуги; - перечень услуг выбранной компании с указанием стоимости; - список заявок, отправленных пользователем; - список заявок, полученных конкретной компанией; - отзывы о выбранной компании и её средний рейтинг. - список избранных услуг пользователя

    Пользователи должны иметь возможность выполнять следующие операции: - зарегистрироваться на платформе; - создать охранную компанию и управлять её данными (для администраторов); - управлять стоимостью услуг, назначать скидки и акции; - отправить заявку на оказание услуги; - изменить статус полученной заявки (для администраторов компании); - оставить отзыв о компании. - добавление и удаление услуг из избранного.

    Необходимо предусмотреть возможность получения отчёта о деятельности охранных компаний на платформе для администраторов.

    Описание основных интерфейсов Guard Market

    1. Аутентификация и регистрация

    Форма входа (LoginView.vue) * Поля: Email и пароль * Валидация обязательных полей * Автоматическая загрузка пользователя после входа * Перенаправление на главную после успешного входа

    Форма регистрации (RegisterView.vue) * Поля: Email, имя, фамилия, отчество, пароль (2 раза) * Валидация паролей на совпадение * После регистрации - автоматический вход

    2. Профиль пользователя (ProfileView.vue)

    • Отображение информации о пользователе
    • Форма редактирования данных (email, ФИО)
    • Возможность создания компании (если нет)
    • Отображение статистики (избранное, заявки)
    • Переход к управлению компанией (если есть)

    3. Главная страница (HomeView.vue)

    • Герой-секция с приветствием
    • Быстрые действия (в зависимости от роли)
    • Описание возможностей платформы
    • Timeline процесса работы
    • CTA для неавторизованных пользователей

    4. Каталог компаний (CompaniesView.vue)

    • Список всех охранных компаний
    • Поиск по названию и описанию
    • Сортировка (по дате, рейтингу, названию)
    • Карточки компаний с логотипом и информацией
    • Клик на карточку - переход к деталям компании

    5. Страница компании (CompanyDetailView.vue)

    • Заголовок компании с логотипом и рейтингом

    • Табы: Услуги и Отзывы

    • Список услуг компании с ценами и скидками

    • Для авторизованных: кнопки "Заявка" и "В избранное"

    • Для владельца: кнопки управления услугами

    6. Управление компанией (CompanyManagementView.vue)

    Вкладки: * Информация - редактирование данных компании

    • Услуги - CRUD операций с услугами

    • Заявки - управление входящими заявками

    • Скидки - создание и управление акциями

    Особенности: * Статистика по заявкам

    • Изменение статусов заявок

    • Добавление комментариев к заявкам

    • Система скидок с датами действия

    7. Каталог услуг (ServicesView.vue)

    • Список всех услуг с фильтрацией

    • Поиск по названию и описанию

    • Фильтр по категориям

    • Сортировка по цене и дате

    • Возможность добавления в избранное

    • Кнопка "Заявка" для авторизованных

    8. Детали услуги (ServiceDetailView.vue)

    • Полное описание услуги

    • Информация о компании-владельце

    • Отображение цены и скидок

    • Кнопки действий (заявка, избранное)

    • Хлебные крошки для навигации

    9. Избранное (FavoritesView.vue)

    • Список избранных услуг пользователя

    • Отображение скидок и текущих цен

    • Возможность быстрой заявки

    • Удаление из избранного

    10. Мои заявки (RequestsView.vue)

    Для обычных пользователей: * Таблица всех заявок с фильтрацией по статусу

    • Поиск по услугам и компаниям

    • Статистика по статусам

    • Возможность редактирования/удаления заявок

    Для владельцев компаний:

    • Вкладка в управлении компанией

    • Изменение статусов заявок

    • Добавление комментариев для клиентов**

    **11. Навигация (Navigation.vue)

    • Адаптивное меню (AppBar + Drawer)

    • Контекстное меню пользователя

    • Отображение уведомлений (бейджи)

    • Быстрый доступ к ключевым разделам

    • Автоматическое скрытие для гостей

    12. UI Компоненты

    Уведомления (SuccessNotification.vue)

    • Всплывающие сообщения об успехе/ошибке

    • Автоматическое скрытие через 3 секунды

    • Иконки и цвета в зависимости от типа

    Диалоги подтверждения (DeleteConfirmationDialog.vue)

    • Модальные окна для опасных действий

    • Подтверждение удаления

    • Загрузочное состояние
